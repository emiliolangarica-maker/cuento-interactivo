# [Cuento interactivo] 🌑

Experiencia web interactiva narrativa — una historia que se revela mientras navegas, con atmósfera y música original.

## 🚧 Estado actual
Proyecto en etapa muy temprana. La estructura que ves ahora (escena1, escena2...) rápido, hecho solo para tener el repo listo — no es la arquitectura final. Va a evolucionar cuando definamos la pantalla principal, la navegación y el sistema de datos (JSON) de la historia.

## 🧩 Cómo trabajamos
Somos un equipo mixto: algunos con más experiencia técnica, otros aprendiendo sobre la marcha (yo incluido). Trabajamos por sprints cortos. Si ves algo que se puede mejorar — código, estructura, buenas prácticas — dilo, estamos abiertos a feedback.

## 🛠️ Stack
HTML, CSS, JavaScript. Sin backend por ahora.
